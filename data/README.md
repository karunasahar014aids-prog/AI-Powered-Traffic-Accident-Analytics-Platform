# Data

Place the prepared accident dataset in this directory for local development.

The repository intentionally ignores common dataset formats (`.csv`, `.xlsx`, `.xls`, `.parquet`) to avoid accidentally committing large or restricted raw data files.

Expected target column: `SEVERITY`

Expected feature columns:

- `SPEED_ZONE`
- `ACCIDENT_TYPE`
- `LIGHT_CONDITION`
- `ROAD_GEOMETRY`
- `DAY_OF_WEEK`
- `HOUR`
- `NO_OF_VEHICLES`
